About This Project

How EcoSort AI is built, and why it's designed this way.

The Problem

Improper waste segregation at source is one of the biggest obstacles to effective recycling and composting. Most households and institutions mix biodegradable, recyclable, e-waste and hazardous items into a single bin, making downstream sorting expensive, unsafe and often impossible. EcoSort AI demonstrates how computer vision can guide correct segregation at the point of disposal, in real time.

How It Works

  1. Capture: The browser grabs frames from the webcam (or an uploaded photo) using the HTML5 Media/Canvas APIs — entirely client-side.
  2. Identification: Each frame is sent to a vision-language AI model, which names every object it sees and assigns each one a waste category directly — not limited to a small fixed list of trainable classes, so it can recognise open-ended, real-world objects.
  3. Category metadata: waste_map.py owns what each of the five categories — Biodegradable, Recyclable, Non-Recyclable, E-Waste, Hazardous — actually means: bin name, color, disposal tip, points. The model only picks the category; the presentation stays consistent.
  4. Guidance: The matched category's disposal tip is displayed on-screen and read aloud (in your chosen language), and the detection is logged to a database for the dashboard, streaks and eco-points.

Why an AI Model Instead of a Fixed Object List?

Traditional lightweight object detectors only recognise a small predefined set of classes (commonly around 80 everyday objects), so anything outside that list is invisible to them. EcoSort AI instead uses a vision-language model that can identify and reason about arbitrary objects, giving genuinely open-ended recognition at the cost of needing an internet connection and an API call per detection, rather than running fully offline.

Tech Stack

Backend

Python, Flask, SQLite

AI

Vision-language model via Hugging Face Inference Providers

Frontend

HTML5, CSS3, vanilla JavaScript, Chart.js

Extras

Web Speech API (voice, multilingual), EcoBot chat assistant

Deployment

The app is deployed as a Docker container to Render, giving it a permanent public URL that works from any device without needing anyone's laptop to stay on. You can also run it locally with python app.py for development.
